# 🚀 GMR 直流有刷电机：高精度串级 PID 与梯形轨迹规划

## 📌 项目简介
本项目基于 STM32 微控制器，针对带有静摩擦力与死区特性的直流有刷减速电机，从零实现了一套工业级精度的闭环控制系统。通过引入梯形加减速规划与位置-速度串级 PID 架构，彻底解决了电机在低速下的稳态抖振与起步顿挫现象，实现了德芙般的丝滑跟随。

## 🛡️ 硬件基石与物理防御
* **核心参数**：查明 GMR 电机减速比为 1:30，编码器 500PPR。结合定时器四倍频，得出外部输出轴转一圈精准对应 60,000 个脉冲。
* **物理降维打击**：将外部供电降至 6V，配合 PWM 安全限幅（如 300），彻底消灭起步大电流导致的单片机死机。
* **引脚装甲**：在 CubeMX 中为 TIM4 编码器引脚开启 Pull-up 上拉，并将 Input Filter 拉满至 15，完美屏蔽电火花带来的虚假脉冲。

## ⚙️ 核心算法与控制逻辑
* **高精度单环位置控制**：成功让电机转动 3 圈（目标值 180,000），最终停在 180,010，稳态误差仅为 10 个脉冲（物理误差 0.06°），达到工业级水准。
* **梯形加减速轨迹规划**：引入“虚拟机械兔”逻辑（`Current_Target`），抛弃瞬间给足目标误差的暴力控制，实现平滑跟随曲线。
* **位置-速度串级 PID**：外环（位置）下发目标速度，内环（速度）强力抗扰执行，消灭纯位置环跟随慢速动态目标时典型的“粘滞-滑移（Stick-Slip）”现象。
* **死区与容忍度优化**：引入“输入死区（Input Deadzone）”消除终点稳态误差震荡；引入“输出偏移（Output Offset）”进行静摩擦力死区补偿，提升极低速动态响应。
